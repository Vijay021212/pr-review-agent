Review levels (how deep a problem is):

- Level 1: Obvious bugs. Formatting and basic syntax are left to linters.
- Level 2: Logic errors, missing conditions, edge cases.
- Level 3: Execution flow, dependencies, regression risks.
- Level 4: Architecture, security, performance, scalability. With concrete evidence only.
- Level 5: Adversarial scenarios and unusual failure combinations. Only when the code gives concrete grounds.
